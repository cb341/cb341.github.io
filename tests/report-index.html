Site check reports

  • Affected pages — selected from changed HTML and asset dependencies.
  • Required browser checks — overflow and JavaScript errors.
  • Visual comparison — screenshots and differences for review.

A report appears after its browser run finishes. Earlier failures can prevent later reports from being generated.

Only affected pages are captured at 360, 768 and 1280 pixels. Unchanged builds skip screenshots and audits.

Download and unzip the artifact, then double-click index.html. These reports work offline; no commands or local server are needed.

Download the separate unlighthouse-report artifact for the affected-page audit dashboard.
