Building the natural numbers

06.10.2026 · Reading example

Dotted underlines explain a term. Hover, focus with Tab, or tap to read; press Escape to close.

We usually write the natural numbers as 0, 1, 2, 3, and so on. The list feels familiar, but “and so on” leaves something unsaid: what rule lets us keep going?

An inductive definition gives us a precise starting point. Zero is a natural number. If n is a natural number, its successor is a natural number too. Every natural number is built by applying these rules a finite number of times.

0,   succ(0),   succ(succ(0)),   …

We call succ(0) “1” and succ(succ(0)) “2”. The familiar numerals are names for objects generated by the definition.

From a rule to a proof

The same structure gives us induction. To prove that a property holds for every natural number, first prove it for zero. Then prove that if it holds for an arbitrary number n, it also holds for succ(n).

The first part is the base case. The second part carries the property from one number to the next. Since every natural number comes from zero by finitely many successor steps, the proof covers them all.

What we start with

In a formal system, an axiom is a statement accepted as a starting point. A theorem is a statement proved from the definitions, axioms, and earlier results.

For example, we can define addition recursively: a + 0 = a, and a + succ(b) = succ(a + b). These equations describe how addition works. Showing that a + b = b + a then requires a proof.

Induction connects these pieces. The definition tells us how the numbers are built; the proof follows that structure, one step at a time.

Definitions
Inductive definition
A definition that specifies starting objects and rules for constructing further objects, with nothing else included.
Successor
The natural number immediately after a given number: succ(n) is what we usually write as n + 1.
Induction
A proof method: establish the property for zero, then show that its truth for n implies its truth for the successor of n.
Base case
The starting case of an inductive proof. For the natural numbers defined here, it is the case n = 0.
Axiom
A statement accepted without proof as a starting point within a particular formal system.
Theorem
A statement established by a proof using the definitions, axioms, and results available in a formal system.
